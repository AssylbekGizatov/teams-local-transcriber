# Микрофон → текст: переносимое Windows-приложение

**Для пользователя нужен готовый ZIP из Releases, а не исходники этой папки.**
Сборка содержит `GigaAM-Microphone.exe`, Python и библиотеки внутри `_internal`,
а также полную модель в `models/gigaam`. Установка Python, pip, Docker,
FFmpeg и доступ в интернет на рабочем компьютере не нужны.

## Начать работу

1. Скачайте готовый `GigaAM-Microphone-windows-x64.zip` из Releases репозитория.
2. Полностью распакуйте архив в обычную папку. Не запускайте EXE прямо из ZIP.
3. Откройте `GigaAM-Microphone.exe`. Не перемещайте EXE отдельно от остальных файлов.
4. Выберите микрофон, подтвердите согласие на запись и нажмите **Записать**.
5. Нажмите **Стоп и распознать**. Дождитесь текста, проверьте его и нажмите
   **Копировать текст** или **Сохранить TXT…**.

Приложение предназначено для Windows 10/11 x64, процессора x86-64 и коротких
записей до пяти минут. Windows ARM64 отдельно не проверен. Рекомендуется
8 ГБ оперативной памяти и несколько гигабайт свободного места для распаковки.
Первое распознавание проверяет контрольные суммы и загружает модель; оно
может занять несколько минут. Скорость зависит от процессора.

При отсутствии микрофона подключите его и нажмите **Обновить**. Если Windows
или политика организации запрещает доступ, обратитесь в ИТ. Приложение не
обходит AppLocker, WDAC, антивирус или SmartScreen и не требует администратора.
Сборка не подписана сертификатом издателя: корпоративное разрешение EXE
может потребоваться даже при наличии всех файлов. Не отключайте защиту.

## Что именно записывается

Только выбранный входной микрофон, только после явного нажатия кнопки.
Это не системный аудиозахват и не бот Microsoft Teams. Звук собеседников
из наушников автоматически не попадает в запись. Получите согласие всех
участников до записи и соблюдайте правила организации.

Исходное аудио находится в памяти процесса и не сохраняется приложением
на диск. Поток микрофона закрывается при остановке, ошибке и выходе;
через пять минут запись автоматически завершается. ОС может использовать
файл подкачки или аварийные дампы: это не обещание защищённого стирания RAM.
Текст сохраняется только по вашей команде; скопированный текст остаётся
в системном буфере обмена по правилам Windows.

## Распознавание и ограничения

Используется локальная **GigaAM Multilingual 220M CTC**, CPU, без LLM и
сторонних сервисов распознавания. Язык определяется самой многоязычной
моделью; принудительный выбор языка не предусмотрен. Качество русского,
казахского, английского и смешанной речи проверяйте на своих разрешённых
примерах. Автоматическое распознавание может ошибаться. Диаризации,
определения говорящих и гарантированного восстановления пунктуации нет.

Длинная запись обрабатывается окнами 24 секунды с секундным перекрытием.
Слова на границе выбираются по временным меткам; возможны ошибки границ.
Перед новым распознаванием сохраните нужный предыдущий текст.

## Офлайн и безопасность

Приложение не устанавливает зависимости и не скачивает модели; используемый
путь распознавания читает только комплектные файлы.
Отсутствующие или повреждённые файлы модели вызывают ошибку, а не скачивание.
Приложение не запускает сетевой сервер. Входной PCM передаётся прямо в
нейросеть: внешний `ffmpeg.exe` не нужен.

При старте включается блокировка сетевых операций через Python socket API
внутри процесса. Она не меняет настройки Windows и не является системным
межсетевым экраном или аудитом сетевого поведения всех native DLL. Отдельно
нужно проверить работу на действительно отключённом от сети целевом ПК.
Контрольные суммы защищают от случайной порчи; сверяйте ZIP с доверенным
файлом SHA256 из того же проверенного выпуска.

## Проверка сборки

Windows CI собирает настоящий EXE, извлекает ZIP в путь с пробелами,
убирает Python из PATH и выполняет проверки frozen-приложения: загрузку
DLL/Tk/PortAudio, GUI с имитацией микрофона и настоящее CPU-распознавание
официального тестового WAV. Отчёты выпуска показывают результат конкретной
сборки. Тестовое аудио не включается в распространяемый архив.

Тест в GitHub runner с урезанным PATH не равнозначен чистой установке
Windows без Python: сам runner содержит Python и системные библиотеки.
CI не проверяет физический микрофон, корпоративные политики или качество
записи на вашем устройстве. Перед массовой установкой ИТ следует проверить
ZIP на чистой Windows VM без Python и с отключённой сетью, затем проверить
реальную запись → Стоп → текст на разрешённом микрофоне.

## Для сборщиков

- Workflow: `.github/workflows/desktop-microphone.yml`.
- Исходники этой папки не заменяют собранный ZIP. Запуск из исходников требует
  отдельной среды разработки и установленных зависимостей.
- Модель и готовые бинарники никогда не коммитятся в Git.
- GigaAM code: `7447938d791c4f3e643386ee22c33777004293a5`.
- Model repo: `ai-sage/GigaAM-Multilingual`, revision
  `2f8a57144e6ec3adfd32fe0484d9ea9913305bc8`.
- Разрешены только заранее проверенные SHA256 config/weights из `engine.py`;
  загрузка весов использует `weights_only=True`, а цели Hydra разрешены явно.
- Лицензии и происхождение runtime, Python/Tcl/Tk, модели, библиотек и
  native-компонентов включаются в ZIP сборочным скриптом. Сохраняйте их при
  распространении. MIT проекта не заменяет лицензии зависимостей.
- ZIP выпуска должен быть меньше 2 GiB; публикация разрешена только после
  успешных frozen-тестов и явного запуска выпуска. Обычный push не выпускает
  новую публичную версию.
