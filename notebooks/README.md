# Микрофон → GigaAM: два notebook

Варианты используют тот же `app.asr.LocalASR` и закреплённые, SHA256-проверяемые веса GigaAM-Multilingual, что и сервис. Готовый аудиофайл не нужен: нажмите Start, произнесите фразу и нажмите Stop. Это **запись → распознавание**, без потоковых частичных результатов, диаризации или автоматических языковых меток. RU, KK, EN и смешанную речь проверяйте на собственных неконфиденциальных примерах; наличие примеров не является оценкой качества.

## Google Colab

[Открыть Colab](https://colab.research.google.com/github/AssylbekGizatov/teams-local-transcriber/blob/main/notebooks/gigaam_microphone_colab.ipynb) · [Исходный notebook](gigaam_microphone_colab.ipynb)

1. Запустите установку и проверку модели: ячейки 1–2.
2. Запустите ячейку 3, нажмите Start и разрешите микрофон браузеру.
3. Нажмите Stop; текст появится после распознавания. Повторный запуск ячейки 3 делает новую запись.
4. Необязательно скачайте TXT и очистите выводы.

Colab передаёт запись в виртуальную машину Google. Это не полностью локальный запуск на вашем компьютере. Используйте только неконфиденциальные тестовые фразы. Google Drive не подключается; внешних STT API нет. GPU можно выбрать в настройках runtime, но его доступность не гарантирована. CPU поддерживается. Зависимости устанавливаются в отдельное окружение, чтобы не заменять пакеты ядра Colab. Нужен поддерживаемый Python 3.11–3.13 (проект проверен на 3.12).

## Локально: Jupyter / VS Code

[Локальный notebook](gigaam_microphone_local.ipynb)

Откройте notebook на своём компьютере и следуйте его инструкции Python 3.12 / выбора локального kernel. Он использует микрофон **машины, на которой выполняется kernel**: при SSH/удалённом Jupyter это сервер, а не ваш ноутбук. Windows разрешения микрофона, FFmpeg, PortAudio и доступность виджетов описаны в notebook. Звук и распознавание остаются на компьютере kernel; интернет нужен для первоначальной установки и загрузки модели. GPU необязателен.

## Общие ограничения и приватность

- До 30 секунд на попытку; для первой проверки достаточно 5–10 секунд.
- Временное аудио удаляется после обработки. Текст может оставаться в памяти и выводах notebook, а скачанный TXT — на вашем устройстве.
- Перед публикацией/сохранением очистите все выводы; затем завершите runtime/kernel для сброса памяти. Очистка не удаляет ранее сохранённые копии и версии.
- Не записывайте чужую речь без согласия. Notebook не подключается к Teams и не захватывает звук встречи автоматически.
- Код сервиса закреплён на `dd7b94a6c680d1ca891eeaa799bd68d70cf2559e`; GigaAM и модель закреплены отдельно в backend и provisioner. Обновление ноутбуков само по себе не меняет код модели.

## Проверки

`python -m pytest -q` включает структурные проверки notebook и компиляцию Python; Colab recorder дополнительно проходит Node.js проверки жизненного цикла с имитацией браузерного API. CI не скачивает веса и не запрашивает настоящий микрофон. Эти проверки **не подтверждают полный запуск в Colab, Windows или VS Code**: права микрофона, доступность устройств, GPU и интерфейс виджетов необходимо проверить в целевой среде. В опубликованных notebook нет сохранённых аудиозаписей, расшифровок или выводов ячеек.
